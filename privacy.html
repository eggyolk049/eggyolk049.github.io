プライバシーポリシー

Chroia Works(クロイアワークス)/ 制定: 2026年9月2日 / 改定: 2026年10月11日(対象のアプリを「Oiko — 家計簿」に変更)

Chroia Works(所在地: 〒105-0013 東京都港区浜松町2-2-15 浜松町ダイヤビル2F。以下「当方」)は、当方が提供するアプリケーション「Oiko — 家計簿」(以下「本アプリ」)および本サイトにおける情報の取り扱いについて、以下のとおり定めます。

1. 記録データの保存場所

本アプリでお客様が入力・記録したデータ(収入と支出の記録、固定費、予算、タグなど)は、すべてお客様の端末内(本アプリの保存領域)に保存されます。当方がこれらのデータを収集・閲覧・保管することはありません。

2. 外部への送信

本アプリは、お客様の記録データを当方のサーバーその他の外部へ送信しません。当方は利用解析(アクセス解析・行動トラッキング)を行っておらず、広告も掲載していません。

なお、本サイトの配信には GitHub Pages(GitHub, Inc.)を利用しており、配信の仕組み上、接続元IPアドレス等の技術的情報がGitHub社により処理されることがあります。詳細は GitHub プライバシーステートメントをご参照ください。

3. データの消失とバックアップ

記録データは端末内にのみ存在するため、アプリの削除、端末の初期化・故障・買い替えなどにより失われることがあります。本アプリの 設定 → 備え にある書き出し機能で、定期的にバックアップを取ることをおすすめします。データ消失について当方は復元の手段を持ちません。

4. データの削除と同意の撤回について

記録データはお客様の端末内にのみ保存され、当方は一切受け取っていません。そのため当方に削除をお求めいただく必要はなく、また当方から削除することもできません。データを消したいときは、本アプリの 設定 → 削除 から記録を削除するか、端末からアプリを削除してください。設定 → 削除 の「全データを削除」で消えるのは、記録・固定費・「今日は 0円」の印です。予算・色・表示などの設定は残ります。設定まですべて消すには、端末からアプリを削除してください。アプリを削除すると、端末内の記録もあわせて消えます。復元はできませんので、必要な記録は「備え」から書き出してから削除してください。

5. 購入情報

本アプリの有料機能をご購入いただく場合、決済は App Store(Apple)の仕組みを通じて行われ、当方がクレジットカード番号等の決済情報を取得することはありません。購入状態の確認のため、App Store が提供する購入情報を本アプリが参照することがあります。

6. お問い合わせ

本ポリシーおよび本アプリに関するお問い合わせは、info@chroia.jp までご連絡ください。お問い合わせでいただいたメールアドレスと内容は、返信と不具合の調査のためにだけ使います。いただいたメールは、消してほしいとお申し出があれば消します。

7. 改定

本ポリシーの内容は、必要に応じて改定することがあります。重要な変更がある場合は本ページでお知らせします。
