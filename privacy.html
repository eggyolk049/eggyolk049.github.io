プライバシーポリシー

Chroia Works(クロイアワークス)/ 制定: 2026年9月2日 / 改定: 2026年9月2日(削除と同意の撤回について追記)

Chroia Works(所在地: 〒105-0013 東京都港区浜松町2丁目2番15号 浜松町ダイヤビル2F。以下「当方」)は、当方が提供するアプリケーション(chroiaシリーズ、以下「本アプリ」)および本サイトにおける情報の取り扱いについて、以下のとおり定めます。

1. 記録データの保存場所

本アプリでお客様が入力・記録したデータ(家計簿の記録、日記、タスク、学習記録、買い物リスト、計算履歴など)は、すべてお客様の端末内(ブラウザのローカルストレージ等)に保存されます。当方がこれらのデータを収集・閲覧・保管することはありません。

2. 外部への送信

本アプリは、お客様の記録データを当方のサーバーその他の外部へ送信しません。当方は利用解析(アクセス解析・行動トラッキング)を行っておらず、広告も掲載していません。

なお、本アプリおよび本サイトの配信には GitHub Pages(GitHub, Inc.)を利用しており、配信の仕組み上、接続元IPアドレス等の技術的情報がGitHub社により処理されることがあります。詳細は GitHub プライバシーステートメントをご参照ください。

3. データの消失とバックアップ

記録データは端末内にのみ存在するため、アプリ(ブラウザ)のデータ削除、端末の初期化・故障・買い替えなどにより失われることがあります。本アプリが備えるエクスポート機能による定期的なバックアップを推奨します。データ消失について当方は復元の手段を持ちません。

4. データの削除と同意の撤回について

記録データはお客様の端末内にのみ保存され、当方は一切受け取っていません。そのため当方に削除をお求めいただく必要はなく、また当方から削除することもできません。データを消したいときは、アプリの設定から記録を削除するか、端末からアプリを削除してください。アプリを削除すると、端末内の記録もあわせて消えます。復元はできませんので、必要な記録は「そなえ」から書き出してから削除してください。

5. 購入情報(ストア版)

アプリストア経由の有料機能をご購入いただく場合、決済は Google Play / App Store の仕組みを通じて行われ、当方がクレジットカード番号等の決済情報を取得することはありません。購入状態の確認のため、ストアが提供する購入情報を本アプリが参照することがあります。

6. お問い合わせ

本ポリシーおよび本アプリに関するお問い合わせは、info@chroia.jp までご連絡ください。

7. 改定

本ポリシーの内容は、必要に応じて改定することがあります。重要な変更がある場合は本ページでお知らせします。
